# WriteWise — IELTS Writing Studio

A responsive front-end MVP for IELTS Academic Writing practice.

## Features
- IELTS Writing Task 1 and Task 2 prompt selection
- Rotating practice prompts
- Essay editor with live word, paragraph and character counts
- Local draft saving in the browser
- Sample responses for testing
- Learning-oriented structure checklist
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a browser, or use a local static server.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then Save.
4. GitHub Pages will publish the site at `https://Greatwmdbobur-web.github.io/IELTS-writing/`.

## Important limitations
This is a front-end MVP. The review checklist uses transparent, rule-based checks and does **not** produce an official IELTS band score, assess all four IELTS criteria, or replace an examiner. Real AI feedback requires a secure server-side API integration; never put a private API key in browser JavaScript.
